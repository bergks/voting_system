# Система Голосования (Voting System)

Консольное приложение для создания, проведения и управления голосованиями.

## Назначение

Программа позволяет зарегистрированным пользователям создавать
голосования с вариантами ответов, голосовать за выбранный вариант
и просматривать результаты. Данные сохраняются между запусками
в JSON-файлах.

## Возможности

- регистрация и вход пользователей (по имени);
- создание голосований с произвольным количеством вариантов;
- голосование за выбранный вариант;
- запрет повторного голосования одним пользователем в одном опросе;
- просмотр результатов голосования;
- просмотр списка всех голосований;
- сохранение и загрузка данных в JSON-файлах.

## Структура проекта
voting_system/
├── main.py — точка запуска и интерфейс программы
├── models.py — логика работы с пользователями, опросами и голосами
├── storage.py — сохранение и загрузка данных (JSON)
├── utils.py — вспомогательные функции ввода
├── data/ — JSON-файлы с данными
│ ├── users.json — пользователи
│ ├── polls.json — голосования
│ └── votes.json — голоса
├── tests/ — автоматизированные тесты
│ ├── test_models.py
│ └── test_votes.py
├── requirements.txt — зависимости проекта
├── .flake8 — настройки линтера
└── README.md

## Требования

- Python 3.10 или выше
- pytest
- flake8

## Установка

Клонировать репозиторий и установить зависимости:

```bash
git clone <ссылка на репозиторий>
cd voting_system
pip install -r requirements.txt
```

## Запуск приложения
```
python main.py
```

После запуска появиться меню голосования
=== Система Голосования ===
1. Войти
2. Создать голосование
3. Проголосовать
4. Показать результаты
5. Показать все голосования
0. Выход

## Запуск тестов
```
python -m pytest tests/ -v
```
