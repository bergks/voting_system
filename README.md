# Система Голосования (Voting System)

## Назначение
Веб-приложение для создания, проведения и управления голосованиями. Пользователи могут создавать опросы с вариантами ответов, голосовать и просматривать результаты в реальном времени.

## Целевая аудитория
- Частные пользователи — проведение опросов среди друзей и коллег;
- Организации и сообщества — принятие коллективных решений;
- Администраторы мероприятий — организация голосований на событиях.

## Предметная область
Платформа, где зарегистрированные пользователи создают голосования с вариантами ответов. Другие пользователи отдают голос за выбранный вариант. Система автоматически подсчитывает результаты. Анонимные пользователи могут просматривать голосования и результаты, но не могут голосовать или создавать опросы.

## Основные сущности
- **Пользователь (User)** — участник системы, создает голосования и участвует в них;
- **Голосование (Poll)** — опрос с вопросом и вариантами ответов;
- **Вариант (Choice)** — вариант ответа в рамках голосования;
- **Голос (Vote)** — выбор пользователем конкретного варианта.

## Основные функции
- Создание голосований с произвольным количеством вариантов;
- Участие в голосованиях;
- Просмотр результатов по каждому варианту;
- Управление опросами (создание, просмотр, редактирование, удаление);
- Аутентификация и авторизация пользователей;

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей;
- разработка REST API;
- контейнеризация приложения;
- настройка CI/CD.
